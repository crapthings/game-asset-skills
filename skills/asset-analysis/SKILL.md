# 资产分析

## 分析流程

1. 读取用户指定的剧本范围、项目 `AGENTS.md` 和已有资产记录；结合实际图片核对可复用素材。
2. 按剧情需要整理角色、场景、道具，标明对应章节或段落；优先复用已有资产，仅为有明确用途的缺口提出新增需求。
3. 区分母版与衍生素材，列出必要的表情、动作、朝向、时间、光照或物件状态变化，以及应引用的已有素材。
4. 整理演出安排：在什么段落显示、替换、隐藏，与哪些人物或道具同屏；剧情需要展示的素材应自动出场，手动查看仅作为补充。
5. 核对需求与剧情状态及画面构图，避免提前展示后文内容、复用状态不符的素材，或在背景和前景重复展示同一道具。

## 交付

- 按用户要求交付；未指定格式时，使用简洁的资产清单与演出表。
- 资产清单包含：资产标识、类型、用途及剧本位置、所需变体、参考来源、已有文件路径、复用或待制作状态。
- 演出表包含：剧本位置、资产标识或变体、显示／替换／隐藏动作，以及必要的站位、层级和对话框避让要求。
- 用户未确定且会影响制作的内容标为待定；区分剧本明确要求与分析建议，不擅自改写剧情或增加玩法。
- 用户要求进入制作时，将明确的需求交给项目中的 `asset-generation` 技能；游戏接入使用演出表，不在本技能中约定渲染技术。
