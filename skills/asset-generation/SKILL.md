# 资产生成

## 项目风格

1. 读取项目 `AGENTS.md` 的美术风格约定，并查看指定的参考图。
2. 未约定时，根据用户要求、上下文和已有资产提出风格及参考图，确认后写入 `AGENTS.md`。用户仅要求探索或参考稿时，可先说明本次风格并生成，不写入项目约定。
3. 角色、场景和道具共用项目风格描述和参考图；角色衍生素材同时引用角色母版。单次风格变化不自动修改项目约定。

## 生成流程

1. 按资产类型读取下方要求及对应参考文件。
2. 使用 Image Gen（`$imagegen`），执行前读取并遵循其说明；默认画面比例为 16:9。
3. 检查输出是否符合构图、内容和项目风格；不一致时调整。需要透明素材时，按[抠图流程](references/background-removal.md)处理。
4. 将交付文件保存到项目目录，报告路径；母版与衍生素材分开保存，未经用户明确要求不覆盖已有资产。

## 角色资产

读取[角色资产流程](references/characters.md)，先建立或复用 turnaround 母版，再生成衍生素材。

## 场景资产

- 提示词按「前景 → 中景 → 背景」组织，描述各层物件及空间关系。
- 使用空镜头，不出现人物或人形剪影。

## 道具资产

读取[道具资产流程](references/props.md)，生成纯绿底道具图，并按需抠图另存透明 PNG。

## 如何存放

- 角色：`references/assets/characters/<角色名称>/`。
- 场景：`references/assets/scenes/<场景名称>/`。
- 道具：`references/assets/props/<道具名称>/`。
- 路径相对项目根目录，同一资产的原图及相关衍生素材集中存放。
